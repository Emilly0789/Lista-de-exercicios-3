Letra A): A memória para um array de tipos primitivos é alocada em um bloco único e contínuo de espaço na memória RAM. Como funciona a alocação Bloco contínuo: Todos os elementos do array ficam armazenados em posições de memória uma após a outra, sem espaços vazios entre eles.Cálculo do tamanho: O sistema multiplica a quantidade de itens pelo tamanho do tipo primitivo. Por exemplo, um array de 5 números inteiros (int de 4 bytes) precisa de um bloco de 20 bytes (5 × 4).Endereço base: A variável que aponta para o array guarda apenas o endereço de memória do primeiro elemento (índice 0). Como funciona a alocaçãoEspaço contínuo: Diferente de estruturas espalhadas, todos os objetos ficam lado a lado na RAM. Se cada objeto ocupa, por exemplo, 32 bytes, uma array com 10 posições vai reservar imediatamente um único bloco de 32 × 10 = 320 bytes contínuos. Cálculo de endereço (Indexação): Como o tamanho do objeto é fixo e conhecido em tempo de compilação ou de criação, o computador acha qualquer posição instantaneamente usando uma fórmula simples:\(\text{Endereço do Índice }i=\text{Endereço Base}+(i\times \text{Tamanho\ do\ Objeto})\)Inline vs. Ponteiros (Depende da linguagem):Em linguagens como C++ ou C, uma array de objetos armazena os valores reais dos atributos de cada objeto em sequência no bloco.Em linguagens como JavaScript, Java ou C#, uma array de objetos geralmente armazena uma sequência de referências (ponteiros) para onde os objetos de fato residem na memória (heap), embora o vetor de referências em si ainda seja contínuo.

Verificar se o Array e o Índice ExistemAntes de acessar um objeto por seu índice, certifique-se de que o array é válido e que a posição existe.Índice fora dos limites: Acessar array[10] em um array com apenas 3 elementos retornará undefined (em JavaScript) ou estourará um erro (em outras linguagens).Array nulo: Se a variável do array for null ou undefined, qualquer tentativa de acesso quebrará a aplicação.
